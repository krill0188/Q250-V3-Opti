# Q250-V3-Opti: 모호성 해소 (CLARIFY)

## 해결 필요 모호성 항목

### 1. 음성인식 엔진 선택
| 옵션 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **A. faster-whisper (CTranslate2)** | 로컬 실시간 STT | 로컬, 빠름, 한국어 지원 | GPU 필요 |
| **B. Sherpa-ONNX** | 온디바이스 STT | 매우 가벼움, 임베디드 최적 | 모델 제한적 |
| **C. Whisper.cpp** | C++ 구현 | 매우 빠름, C++ 통합 용이 | Python 바인딩 필요 |

**결정**: **A (faster-whisper)** - 기존 hybrid-drone-deception에서 검증됨, Python 생태계 호환성 최고

### 2. Non-GPS 센서 융합 아키텍처
| 옵션 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **A. EKF 단일 필터** | 모든 센서를 하나의 EKF에 융합 | 구현 단순, 일관성 | 계산량 큼, 튜닝 어려움 |
| **B. 다중 EKF + 페더레이션** | 센서별 EKF 후 상위에서 융합 | 모듈화, 장애 격리 | 복잡도 높음 |
| **C. PX4 내장 EKF2 + 외부 보정** | PX4 EKF2 사용, 외부 Non-GPS 보정만 추가 | PX4 생태계 활용, 검증됨 | 커스터마이징 제한 |

**결정**: **C (PX4 EKF2 + 외부 보정)** - PX4 검증된 EKF2 활용, Non-GPS는 외부에서 위치/속도 보정 주입

### 3. 다이브 모드 전환 트리거
| 옵션 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **A. 완전 자동** | 고도/속도/위협 기반 자동 전환 | 반응 빠름, 조종사 부담 없음 | 오작동 위험 |
| **B. 반자동 (권장)** | 자동 조건 충족 시 알림, 조종사 승인 후 전환 | 안전성, 조종사 권한 유지 | 반응 지연 가능 |
| **C. 완전 수동** | 조종사 수동 명령만으로 전환 | 완전한 제어권 | 반응 느림, 부담 큼 |

**결정**: **B (반자동)** - 안전성 확보, 조종사 최종 권한 유지, 자동 조건 충족 시 알림만

### 4. 기만 패턴 자동 선택 로직
| 옵션 | 설명 | 장점 | 단점 |
|------|------|------|------|
| **A. 위협 유형 매핑** | IR→SPIRAL, RADAR→SINE, OPTICAL→FAKE_CRASH | 직관적, 구현 단순 | 복합 위협 대응 어려움 |
| **B. 점수 기반 선택** | 각 패턴별 효과도 점수 계산 후 최고점 선택 | 유연함, 복합 위협 대응 | 튜닝 복잡 |
| **C. 강화학습 에이전트** | 상황 기반 최적 패턴 학습 | 최적화 가능 | 학습 데이터/시간 필요, 검증 어려움 |

**결정**: **A + B 혼합** - 기본 위협 유형 매핑 + 복합 위협 시 점수 기반 선택
