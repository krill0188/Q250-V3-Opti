# Silvus StreamCaster 초기 설정 체크리스트

## 1. 펌웨어 통일 (최중요)
- [ ] 모든 장비(GDT + Air 4대) 동일 펌웨어 버전으로 업데이트
- [ ] 웹 UI → System → Firmware Update → .bin 파일 업로드
- [ ] 버전 불일치 시 매쉬 형성 안 됨 / 불안정

## 2. 무선 설정 (웹 UI → Radio → Configuration)
- [ ] 주파수 밴드: 국내 전파법 허용 대역 확인 (2.4GHz/5.8GHz 중 택1)
- [ ] 채널 폭: 20 MHz (안정성) 또는 40 MHz (처리량↑)
- [ ] TX 파워: 최대(5W) — 기체 발열/배터리 확인 후 조정
- [ ] 모드: Mesh (MANET) — 고정
- [ ] 암호화 키: AES-256 키 동일하게 (32바이트 Hex) — 모든 장비 동일

## 3. 안테나 다양체 확인
- [ ] 웹 UI → Radio → Status → Antenna Diversity → "Enabled" 확인
- [ ] RSSI 차이 < 3dB 면 양호

## 4. 매쉬 형성 테스트
- [ ] GDT 단독 부팅 → 웹 UI Mesh Topology → "Gateway" 표시 확인
- [ ] Air Unit 1대 부팅 → Topology에 "Node 1" 나타나는지, RSSI/SNR 확인
- [ ] 2대, 3대, 4대 순차 추가 → 각 홉 수(Hops=1) 확인
- [ ] 기체 이동하며 링크 유지/재형성 확인

## 5. 네트워크/IP 설정
- [ ] PC 고정 IP: 192.168.10.1/24
- [ ] GDT 게이트웨이: 192.168.10.254
- [ ] 기체 1: 192.168.10.11, 기체 2: 192.168.10.12, 기체 3: 192.168.10.13, 기체 4: 192.168.10.14
- [ ] 관리 VLAN: 10.10.10.0/24 (태그드)

## 6. MAVLink/ROS2 트래픽 테스트
- [ ] ping -i 0.01 -c 1000 192.168.10.11 → 평균 < 10ms, 지터 < 2ms, 손실 < 0.01%
- [ ] QGC 연결: UDP 14550 → 하트비트 1Hz, 파라미터 다운로드 속도 확인
- [ ] ROS2 토픽: hz / silvus/rssi → 1Hz 정상

## 7. 실버스 특화 설정 확인
- [ ] 안테나 다양체: 웹 UI → Radio → Status → Antenna Diversity → "Enabled"
- [ ] TDMA 슬롯 자동 할당 확인 (고정 슬롯 설정 안 함)
- [ ] AES-256 키 동일 입력 확인
- [ ] 관리 VLAN 태깅: 10.10.10.0/24 (웹 UI/펌웨어용)

## 8. 국내 전파법 준수 확인
- [ ] 주파수/출력 전파법 제23조/제24조 준수 확인
- [ ] 5.8GHz 5W 불법 여부 확인 → 필요시 2.4GHz 1W 이하 또는 면허 취득
- [ ] KC 인증 여부 확인

## 9. 하드웨어 장착 확인
- [ ] MIMO 안테나 2개: λ/2(~6cm@2.4GHz) 이상 이격, 대각선 모서리
- [ ] UBEC 12V/5A 별도 장착 (Jetson 5V 라인과 분리)
- [ ] 이더넷 직결 (Jetson eth0), 시리얼 백업 (FC TELEM3)
- [ ] 진동 방지 마운트, 히트싱크/쿨링팬 장착

## 10. 키 관리
- [ ] AES-256 키 분기별 로테이션 계획 수립
- [ ] 키 오프라인 저장 (하드웨어 보안 모듈 또는 종이)
- [ ] 키 유출 시 대응 절차 문서화
