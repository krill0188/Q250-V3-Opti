# 온보드 마이크 어레이 하드웨어 설계 가이드
## Q250-V3-Opti 음성 제어 시스템 - 프로펠러 소음(Ego-noise) 제거 1단계: 하드웨어/기구적 차폐

---

## 1. 개요
본 문서는 Q250-V3-Opti 드론 플랫폼에 탑재되는 온보드 마이크 어레이의 하드웨어/기구적 설계 가이드입니다. **프로펠러 소음(Ego-noise) 제거 3단계 파이프라인**의 **1단계(하드웨어/기구적 차폐)**에 해당하며, 물리적 소음 유입을 **10~15dB 이상** 줄이는 것을 목표로 합니다.

> **핵심 원칙**: 소프트웨어 알고리즘(DSP/DNN) 이전에 물리적 소음 유입을 차단하는 것이 가장 효과적입니다. 1단계에서 10dB 이상 줄이면, 후속 DSP/DNN 단계의 부담이 대폭 감소합니다.

## 2. 마이크 어레이 배치 설계

### 2.1 배치 위치 (프로펠러 후류 회피)
```
          [프로펠러 1]    [프로펠러 2]
               \            /
                \          /
                 \        /
                  \      /
                   \    /
                    \  /
                     \/
              [기체 중앙]
                     |
                     |  ← 마스트 (20cm 연장)
                     |
              [마이크 어레이]  ← 기체 상단에서 20cm 위
```

| 항목 | 사양 | 비고 |
|------|------|------|
| **마스트 높이** | 기체 상단에서 **20cm 연장** | 프로펠러 회전 평면에서 20cm 이격 |
| **수평 위치** | 전방 카메라 짐벌 방향 돌출 | 프로펠러 후류(Downwash) 회피 |
| **기체 중심에서 거리** | 전방 30cm, 상방 20cm | 무게 중심 영향 최소화 |
| **프로펠러 회전 평면 이격** | ≥ 20cm | 풍절음/와류 회피 |

### 2.2 마이크 어레이 구성
| 항목 | 사양 | 비고 |
|------|------|------|
| **채널 수** | **4채널** (원형/사각 배치) | 빔포밍/빔포밍+적응형 필터용 |
| **마이크 간격** | **5cm** (파장 고려: 16kHz에서 λ≈2.1cm) | 공간 샘플링 정리 |
| **배치 형태** | 정사각형 (5cm × 5cm) | 4채널 평면 어레이 |
| **마이크 모델** | **SPH0645LM4H** (I2S, MEMS) | 64dB SNR, -26dBFS, 16-48kHz |

```
채널 배치 (평면도):
    [Mic 0]    [Mic 1]
        ●──────●  (5cm)
        │      │
        │      │  (5cm)
        ●──────●
    [Mic 3]    [Mic 2]

채널 매핑:
  Ch0: 전방-좌측 (Forward-Left)
  Ch1: 전방-우측 (Forward-Right)  
  Ch2: 후방-우측 (Rear-Right)
  Ch3: 후방-좌측 (Rear-Left)
```

## 3. 진동 차단 시스템 (Structure-borne Noise Isolation)

### 3.1 2중 차단 구조
```
[마이크 PCB]
     │
     ├── 1차: 소르보탄(Sorbothane) 2mm 패드
     │       - 전단 탄성률: 0.5 MPa
     │       - 댐핑 계수: 0.15
     │
     ├── 2차: 실리콘 방진 볼 (M3, 높이 10mm)
     │       - 공진 주파수: 15Hz 이하
     │       - 최대 하중: 500g
     │
     └── [마스트/카본 프레임]
```

### 3.2 부품 사양 (BOM)
| 부품 | 모델/사양 | 수량 | 비고 |
|------|-----------|------|------|
| **소르보탄 패드** | 2mm 두께, 20×20mm | 4개 | PCB 네 모서리 |
| **실리콘 방진 볼** | M3, 높이 10mm, 경도 40A | 4개 | PCB-마스트 연결 |
| **M3 나사/너트** | 스테인리스, 와셔 포함 | 8세트 | 고정용 |
| **열수축 튜브** | 2mm, 절연용 | 적당량 | 배선 보호 |

## 4. 풍절음 차단 (Aerodynamic Noise Shielding)

### 4.1 2중 윈드실드 구조
```
[마이크 캡슐]
     │
     ├── 1차: 오픈셀 어쿠스틱 폼 (10mm 두께)
     │       - 기공률: 95% 이상
     │       - 공기 투과율: > 90%
     │       - 주파수 응답: 20Hz~20kHz 평탄
     │
     └── 2차: 인조 모피 데드캣 (Deadcat)
             - 파일 길이: 15mm
             - 밀도: 300g/m²
             - 풍속 10m/s에서 25dB 이상 감쇠
```

### 4.2 커버 사양
| 부품 | 사양 | 수량 | 비고 |
|------|------|------|------|
| **어쿠스틱 폼** | 오픈셀, 10mm, 50×50mm | 4개 | 각 마이크 개별 |
| **데드캣 커버** | 인조 모피, 4채널 일체형 | 1개 | 어레이 전체 커버 |
| **고정 밴드** | 실리콘 고무, 직경 25mm | 4개 | 폼 고정용 |

## 5. 전기/인터페이스 설계

### 5.1 I2S 배선 (4채널)
| 신호 | 핀 | 비고 |
|------|-----|------|
| **BCLK** | GPIO 18 | 비트 클럭 (3.072MHz @ 16kHz) |
| **LRCLK** | GPIO 19 | 좌우 채널 클럭 (16kHz) |
| **DATA0** | GPIO 20 | Ch0, Ch1 (TDMA) |
| **DATA1** | GPIO 21 | Ch2, Ch3 (TDMA) |
| **VDD** | 3.3V | MEMS 전원 |
| **GND** | GND | 공통 그라운드 |

### 5.2 전원 노이즈 필터
- **페라이트 비드**: 600Ω @ 100MHz (전원 라인)
- **커패시터**: 10μF + 0.1μF 병렬 (VDD-GND 디커플링)
- **LDO**: 저잡음 3.3V 레귤레이터 (TPS7A4700 권장)

## 7. 통합 인터페이스 (소프트웨어 연동)

### 7.1 데이터 포맷 (ROS2 토픽)
```yaml
# /audio/mic_array_raw (4채널 원시 데이터)
std_msgs/Header header
uint32 sample_rate: 16000
uint8 channels: 4
int16[] data  # 인터리브드: Ch0, Ch1, Ch2, Ch3 순서

# /audio/mic_array_processed (전처리 후 단일 채널)
std_msgs/Header header
uint32 sample_rate: 16000
int16[] data  # 빔포밍+노이즈 제거 후
```

### 7.2 소프트웨어 파이프라인 연동
```python
# voice/kws_runtime.py 에서 호출 예정
class MicArrayInterface:
    def __init__(self):
        self.sub_raw = rospy.Subscriber('/audio/mic_array_raw', AudioData, self._raw_cb)
        self.pub_processed = rospy.Publisher('/audio/mic_array_processed', AudioData, queue_size=10)
        
        # 노이즈 리덕션 파이프라인
        self.noise_reducer = PropellerNoiseReducer()
        self.dnn_denoiser = DNNNoiseSuppression()
    
    def _raw_cb(self, msg):
        # 4채널 → 빔포밍 → DSP → DNN → 단일 채널
        enhanced = self.noise_reducer.process(msg.data)
        clean = self.dnn_denoiser.process(enhanced)
        self.pub_processed.publish(clean)
```

## 8. 부록: 조립 순서도

```
1. 마이크 PCB 준비 (SPH0645LM4H × 4, I2S 배선 완료)
        ↓
2. 소르보탄 패드 부착 (PCB 4개 모서리)
        ↓
3. 실리콘 방진 볼 체결 (M3 나사, 토크 0.3Nm)
        ↓
4. 마스트에 고정 (M3 볼트, 토크 0.5Nm)
        ↓
5. 어쿠스틱 폼 부착 (마이크 캡슐 개별)
        ↓
5. 데드캣 커버 씌우기 (어레이 전체)
        ↓
6. I2S 배선 연결 (JST-SH 6핀 커넥터)
        ↓
7. 전원/그라운드 필터 회로 연결
        ↓
8. 기능 테스트 (I2S 클럭, 데이터 라인 확인)
        ↓
9. 환경 테스트 (진동/풍절음/자기소음)
        ↓
10. 비행 테스트 (SITL → 실외)
```
