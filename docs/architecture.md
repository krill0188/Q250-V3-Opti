### 1.1 계층별 상세 구성

| 계층 | 구성요소 | 기술 스택 | 실시간성 | 안전 등급 |
|------|----------|-----------|----------|-----------|
| **센서** | IMU, Baro, Mag, GPS, Optical-Flow, LiDAR, RealSense, RC | 하드웨어 드라이버 | 400Hz~10Hz | - |
| **추정/인식** | EKF2, VIO, Optical-Flow fusion, 장애물 맵핑 | PX4 내장, ROS 2 노드 | 100~30Hz | **Critical** |
| **계획/결정** | 미션 플래너, 로컬 플래너, AI/LLM 고수준 플래너 | ROS 2, Python, (LLM API) | 10~1Hz | High |
| **제어** | Position/Velocity/Attitude/Rate 컨트롤러 | PX4 내장 (C++) | 400Hz | **Critical** |
| **통신** | MAVLink, uXRCE-DDS, MAVLink Router, Fast-DDS, Silvus | C++, Python | 50~10Hz | High |
| **안전/감독** | Failsafe, Geofence, Watchdog, RC 킬스위치 | PX4 내장, 하드웨어 | 10~1Hz | **Critical** |

## 2. 결정론적 계층 vs 보조 계층 (핵심 원칙)

```
┌─────────────────────────────────────────────────────────────────┐
│                    결정론적 안전 계층 (Deterministic Safety)       │
├─────────────────────────────────────────────────────────────────┤
│  • PX4 Attitude/Rate Controller (400Hz)                          │
│  • PX4 Position/Velocity Controller                              │
│  • EKF2 Estimator (센서 융합, Innovation 모니터링)                │
│  • Failsafe: RC Loss, Battery, Geofence, Link Loss              │
│  • Actuator Outputs (DShot → ESC → Motor)                       │
│                                                                 │
│  특징: 검증된 C++ 코드, 실시간 OS, 결정론적 타이밍,              │
│        공식 문서/테스트 스위트, 인증 가능                         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼ (안전 인터페이스: setpoint, mode, limits)
┌─────────────────────────────────────────────────────────────────┐
│                    보조 지능 계층 (Assistive Intelligence)         │
├─────────────────────────────────────────────────────────────────┤
│  • VIO Estimator (ROS 2, Python/C++)                            │
│  • Local Planner (TEB/DWA/커스텀, ROS 2)                        │
│  • Obstacle Mapping (Costmap, Voxel Grid)                       │
│  • AI 객체 인식 (YOLO/Segformer, TensorRT)                      │
│  • LLM 고수준 플래너 (자연어 → 웨이포인트/제약조건)              │
│  • 로그 분석/설명 (LLM 기반)                                    │
│                                                                 │
│  특징: 비결정론적 가능, 학습/추론 기반, 실패 시 안전 계층으로    │
│        폴백, 검증 데이터셋 필요, 버전 관리 필수                   │
└─────────────────────────────────────────────────────────────────┘
```

**절대 규칙**: **보조 계층이 결정론적 계층의 최종 권한을 우회하지 못한다.**

- 보조 계층 출력 → **검증/제한 필터** → 결정론적 계층 입력
- 결정론적 계층은 항상 **최종 거부권(veto)** 보유
- 통신 단절/크래시 시 결정론적 계층이 **자동으로 안전 상태 전환**

### 4.1 LLM 출력 검증 필터 (필수)
```python
# 안전 검증 필터 예시 (모든 LLM 출력 통과 필요)
def validate_llm_output(llm_result: dict) -> tuple[bool, str]:
    """
    Returns: (is_valid, error_message)
    """
    # 1. 좌표계 확인 (ENU/NED 혼동 방지)
    if 'waypoints' in llm_result:
        for wp in llm_result['waypoints']:
            if not (-90 <= wp['lat'] <= 90 and -180 <= wp['lon'] <= 180):
                return False, f"Invalid lat/lon: {wp}"
            if wp['alt'] < 0 or wp['alt'] > 1000:  # 고도 제한
                return False, f"Altitude out of range: {wp['alt']}"
    
    # 2. 안전 범위 확인 (Geofence 내)
    if 'geofence' in config:
        for wp in llm_result.get('waypoints', []):
            if not point_in_polygon(wp, config['geofence']):
                return False, f"Waypoint outside geofence: {wp}"
    
    # 3. 중복/이상 웨이포인트 제거
    # 4. 속도/가속도 제한 확인
    # 5. 금칙어/위험 명령 차단 ("최대 속도", "충돌 무시" 등)
    
    return True, "OK"
```

### 6.1 링크 품질 → 비행 동작 연동
```python
# scripts/silvus_monitor.py에서 발행하는 토픽 예시
# /silvus/link_quality (std_msgs/Float32MultiArray)
# [rssi_dbm, snr_db, packet_loss_pct, rtt_ms, hop_count]

# 플래너에서 구독하여 동적 파라미터 조정
def silvus_quality_callback(self, msg):
    rssi, snr, loss, rtt, hops = msg.data
    
    if loss > 10.0 or rtt > 50.0:
        # 링크 열화: 안전 모드 진입
        self.planner.max_vel_x *= 0.5
        self.planner.inflation_dist *= 1.5
        # PX4 OFFBOARD 타임아웃 단축
        self.set_px4_param('COM_OF_LOSS_T', 0.5)
        
    elif loss < 2.0 and rtt < 20.0:
        # 링크 양호: 정상 모드 복구
        self.planner.max_vel_x = self.config['max_vel_x_nominal']
        self.planner.inflation_dist = self.config['inflation_dist_nominal']
        self.set_px4_param('COM_OF_LOSS_T', 1.0)
```

## 9. 안전 인증 체크리스트 (개발 단계별)

| 단계 | 인증 항목 | 검증 방법 | 통과 기준 |
|------|-----------|-----------|-----------|
| **개발** | 단위 테스트 커버리지 | `colcon test` + `pytest` | ≥ 80% (핵심 모듈 100%) |
| **SITL** | 회귀 테스트 스위트 | Gazebo + PX4 SITL 자동화 | 50회 연속 무결함 |
| **벤치** | 하드웨어 인더 루프 (HITL) | 실 FC + 시뮬 센서 | 전 모드 전환 정상 |
| **무프로펠러** | 통신/추정/제어 검증 | 실 센서, 프로펠러 제거 | EKF2 혁신 ±3σ, OFFBOARD 2Hz |
| **초도 비행** | 저고도 수동/Position | 실내/외 안전 구역 | 호버 ±0.2m, RC 비상복귀 즉시 |
| **자율 비행** | Mission/RTL/회피/Geofence | 시나리오 기반 테스트 | 전 시나리오 통과, 로그 분석 OK |
| **군집 비행** | 다중 기체 동시 운용 | 2→4대 순차 확장 | 링크 품질 유지, 충돌 없음 |

## 11. 요약: 아키텍처 핵심 원칙 10계명

1. **결정론적 계층(PX4)이 최종 권한**을 가진다. 보조 계층은 제안만 한다.
2. **실시간 루프(400Hz~10Hz)와 비실시간 계층(LLM 등)은 엄격히 분리**한다.
3. **모든 센서/추정/제어 데이터는 프로비넌스(SHA-256, 버전, 타임스탬프)와 함께 저장**한다.
4. **Failsafe는 하드웨어/펌웨어 레벨에서 다중 계층으로** 구현한다 (RC, 배터리, 링크, 지오펜스, 워치독).
5. **Silvus 데이터링크 품질은 비행 파라미터에 실시간 피드백**되어 안전 마진을 동적 조정한다.
6. **VIO/External Vision은 EKF2 혁신 모니터링 하에서만** 융합된다.
7. **Fake GPS는 Global Position 필수 기능(Mission/RTL/Geofence)용으로만** 활성화한다.
8. **자율 회피는 비AI(Costmap+TEB/DWA)부터 완성**하고, AI 객체 인식은 선택적으로 추가한다.
9. **LLM 출력은 안전 검증 필터(좌표계, 범위, 금칙어)를 반드시 통과**해야 실시간 계층에 입력된다.
10. **모든 아키텍처 변경은 ADR로 기록**하고, 비행 테스트 검증 후 병합한다.
